8.Raspberry Pi Expansion Board Configuration ​

If you use the image installed online using official tools to control the expansion board, please follow the steps below to configure the environment first.

  1. Refer to relevant tutorials in “4. Raspberry Pi Board & Expansion Board Course/1. Raspberry Pi 5 Controller” to configure the environment and hardware successfully.

  2. After correctly configuring according to the tutorial, open the “MobaXterm” remote connection tool and connect to the Raspberry Pi. For more specific instructions, please access lesson 2 in “1.Raspberry Pi 5 Controller/2. Raspberry Pi 5 Basic Operation and Configuration”.

  3. After connecting, enter the command to modify the serial port.

bash
sudo nano /boot/firmware/config.txt
  1. In the pop-up page, scroll to the end of the text. Enter the following code to modify the serial port configuration.
usb_max_current_enable=1
avoid_warnings=1
enable_uart=1
dtparam=uart0=on

  1. Press "Ctrl+S" to save. Then, press “Enter” and “Ctrl+X” in turn to return. After it returns, enter “sudo reboot” to restart the Raspberry Pi.

  2. After booting, enter the command to view the serial port direction.

bash
ls /dev - al

  1. Locate the content shown in the figure below, which indicates that the modification is successful.

  2. After the modification is successful, refer to lesson 2 in “1.Raspberry Pi 5 Controller/2. Raspberry Pi 5 Basic Operation and Configuration”, and transfer the “board_demo” in the appendix located in “2. Raspberry Pi Expansion Board Course” to the “/home/pi/” path of the Raspberry Pi.

Board Demo Source Code ​

The appendix source code is located in 4. Raspberry Pi Board & Expansion Board Course/2. Raspberry Pi Expansion Board Course/Appendix/board_demo and includes the following files:

  • button_demo.py
  • buzzer_demo.py
  • imu_demo.py
  • led.py
  • rgb_demo.py
  • ros_robot_controller_sdk.py
