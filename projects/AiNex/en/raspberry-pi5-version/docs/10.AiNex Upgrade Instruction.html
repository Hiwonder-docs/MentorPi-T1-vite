10.1 Upgrade Instruction of AiNex Raspberry Pi 5 Version ​

AiNex offers two versions of the main controller, Raspberry Pi 4B and Raspberry Pi 5, for you to choose from.

The AiNex of Raspberry Pi 5 version has also received upgrades on the expansion board. This provides AiNex higher performance and faster response speed in functions such as motion control and vision applications.

The differences between the Raspberry Pi 4B and Raspberry Pi 5 versions of AiNex are shown below:

  1. In terms of appearance, except for the difference in the main controller, the overall design remains the same.

2. In terms of the built-in system, the Raspberry Pi 4B version of AiNex comes with Debian 10 as the operating system and pre-installed ROS Noetic Ninjemys. All software, function programs run on this system.

On the other hand, the Raspberry Pi 5 version comes with Debian 12. A Docker container system of Ubuntu 20.04 and ROS Noetic Ninjemys are created as the development environment for AiNex.

By using Docker container technology, the Raspberry Pi 5 version isolates the ROS running environment. It not only keeps the basic operating system stable, but also provides a separate and easier-to-maintain environment for ROS. This achieves compatibility between different versions of ROS and the operating system, improves the security of ROS updates and runtime processes, and allows for better isolation of system resources and unified runtime environments across different platforms, which in turn brings portability to development and testing.

  1. Regarding function games, the new version remains largely consistent with the previous one. The only difference is that to stop the ROS service, you need to run the “~/.stop_ros.sh” script under Docker. To start it, you need to exit the Docker environment and enable the automatic startup service with “sudo systemctl restart start_node.service”.

4. There are significant differences in the underlying control of AiNex's Raspberry Pi 4B and Raspberry Pi 5 versions. The Raspberry Pi 4B version of AiNex uses an expansion board loaded with an IC chip. It communicates with the IC chip through the I2C communication protocol, achieving the control for the underlying hardware, such as servos and LED lights with the GPIO port.

After being upgraded, the expansion board for the Raspberry Pi 5 version is equipped with a 32-bit ARM master control chip. It adopts CRC (Cyclic Redundancy Check) algorithm to communicate with the 32-bit ARM master control chip to drive the underlying hardware. This upgrade greatly improves the reliability and integrity of data transmission, as well as the response speed of AiNex’s underlying control.

  1. The courses for both versions of AiNex are still highly universal and not changed much. Therefore, most of the video demonstrations are still based on the 4B version, which is equally applicable to the Raspberry Pi 5 version.

  2. For terminal usage, when using MobaXterm to connect, you need to enter commands to enter the Docker environment. When using VNC to connect, there are two terminals to choose from. accesses directly to the Docker environment. requires you to enter commands to enter the Docker environment.

With the same appearance, more detailed tutorials, more powerful controller, and more stable expansion board, AiNex greatly enhances your experience and expands its playability.
