9.1 Remote Control ​

There are two ways to remotely control the robot: graphical and command-line control.

VNC is a graphical remote control software. After installation, you can directly control the robot on your computer by connecting to the robot's hotspot. If the VNC is used for the Raspberry Pi 5 controller, the robot's system desktop can be clearly seen. This is convenient for intuitive operation.

Compared to VNC, MobaXterm is an SSH connection that focuses more on command-line control. It does not display the complete desktop of the robot's system, only the command-line window. If you are proficient in command-line operations, you can use commands to control the robot more quickly while reducing computational and memory usage. MobaXterm has a built-in lightweight X11 server that can directly display the interface of graphical applications.

The tutorial for this robot uses MobaXterm connection as an example for demonstration, and it is also applicable for VNC.

For terminal usage, when using MobaXterm to connect, you need to enter commands to enter the Docker environment.

When using VNC to connect, there are two terminals to choose from. accesses directly to the container. requires you to enter commands to enter the Docker environment.

Enter “docker exec -it -u ubuntu -w /home/ubuntu 82df /bin/bash” can enter the container. Enter “exit” can exit the container.

Stopping the ROS service needs to run the “~/.stop_ros.sh” script under Docker. Starting it needs to exit the Docker environment and enable the auto-start service with “sudo systemctl restart start_node.service”.
