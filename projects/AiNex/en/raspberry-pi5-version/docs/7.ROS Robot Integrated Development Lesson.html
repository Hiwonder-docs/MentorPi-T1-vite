7.1.1 Autonomous Getting Up ​

7.1.1.1 Program Logic ​

First, the robot will read the x, y, and z axis data from the MPU6050 sensor on the expansion board to determine if it is in a fallen state.

Then, based on the fallen state, it will assess whether it has fallen forward or backward. After waiting for a period of time and confirming that the three-axis data indicates a fallen state, it will execute a set of actions to help the robot stand up, choosing different standing actions based on the type of fall.

        # 主循环函数(main loop function)

                        common.loginfo('lie_to_stand')
                        self.motion_manager.run_action(self.lie_to_stand_action_name)
                    elif self.state == 'recline_to_stand':
                        common.loginfo('recline_to_stand')
                        self.motion_manager.run_action(self.recline_to_stand_action_name)
                    time.sleep(0.5)
                    self.state = 'stand'  # 起立后切换到站立状态(switch to standing state after raising up)
                else:
                    time.sleep(0.01)
            else:
                time.sleep(0.01)

        rospy.signal_shutdown('shutdown')

  • Line-following logic processing function
python
    def process(self, x, width):
        # 左右根据x坐标值进行调整(adjust left and right based on x-coordinate value)
        center_x = width/2 + self.calib_config['center_x_offset']
        # print(x)
        if abs(x - center_x) < 10:
            yaw_output = 0
        elif abs(x - center_x) < width/6:
            yaw_output = math.copysign(1, x - center_x) + misc.val_map(x - center_x, -width/6, width/6, self.yaw_range[0] + 1, self.yaw_range[1] - 1)
        else:
            yaw_output = math.copysign(self.yaw_range[1], x - center_x)
        
        # print(x, center_x, yaw_output)
        # 转弯时前进步幅减小(When turning, decreases forward step length)
        #print(yaw_output)
        if abs(yaw_output) > 6: 
            x_output = 0.008
        else:
            x_output = self.x_max
        if abs(yaw_output) < 4:
            self.gait_manager.set_step(self.go_dsp, x_output, 0, int(-yaw_output), self.go_gait_param, arm_swap=self.go_arm_swap, step_num=0)
        else:
            self.gait_manager.set_step(self.turn_dsp, x_output, 0, int(-yaw_output), self.turn_gait_param, arm_swap=self.turn_arm_swap, step_num=0)

The first parameter "x" is the center value of the detected line.

The second parameter "width" is the width of the image, which is 640.

First, the center value of the image "center_x" is obtained by adding half of the image width to the calibration offset of the image.

Then, the difference between the center value of the image and the center value of the line is calculated. Depending on the absolute value of this difference, different turning angles are calculated. The math.copysign() function outputs the absolute value of the first parameter and the sign of the second value.

Finally, based on the magnitude of the turning angle, the step size for forward movement and the gait parameters used are set.

                self.gait_manager.set_body_height(0.06, 1)  # 设置身体高度为0.06m(set body height to 0.06m)

                                                              [24, self.state[self.current_state][0][1]]])

In this lesson, we integrate tag recognition for positioning and color recognition for locating sponge blocks. Let's now explore the comprehensive workflow for this section:

To begin, we subscribe to the '/object/pixel_coords' topic to obtain color recognition results. By adhering to the predefined color order, we identify the position of the sponge block and approach it for manipulation.

Subsequently, we subscribe to the '/tag_detections' topic to retrieve tag recognition results. These tag positions guide us in achieving the placement process.

    def run(self):
        while self.running:
            if self.start:
                if self.object_info is not None:    # 如果检测到目标(if the target is detected)
                    if self.start_find_block:       # 需要搜寻的标志置为False(set the searching flag to False)
                        self.start_find_block = False
                    # 进行跟踪(perform the tracking)
                    elif self.body_track_process(self.rl_dis, self.ud_dis, self.object_info):
                        # 根据状态进行初始化(perform the initialization based on the state)
                        if self.transport_state == 'pick_block':    # 代表着去搬运方块的状态(represent the state for picking up the block)
                            self.find_tag_init()                            
                        elif self.transport_state == 'place_block': # 代表着去放置区放置方块的状态(represent the state for placing the block to the placement area)
                            self.find_block_init()
                    self.count_miss = 0  # 重置丢失次数(reset the miss count)
                else:                    # 如果未检测到目标(if the target is not detected)
                    if not self.start_find_block:
                        self.count_miss += 1        # 记录丢失次数(record the miss count)
                        if self.count_miss > 100:   # 如果超过阈值则置标志位开始搜寻(If the count exceeds the threshold, set the flag to start searching)
                            self.count_miss = 0
                            self.start_find_block = True
                            self.start_index = 0
                    else:
                        self.find_process()         # 搜寻过程(the finding process)
                time.sleep(0.01)
            else:
                time.sleep(0.01)

        self.init_action(self.head_pan_init, self.head_tilt_init)   # 停止头部动作(stop the action of head)
        self.stop_srv_callback(None)        # 停止检测(stop detection)
        rospy.signal_shutdown('shutdown')   # 关闭节点(close node)

The program first checks whether the target is detected. If it is detected, it sets the state of self.start_find_block to false. Then it calls the self.body_track_process process to track and approach the target.

After tracking and approaching the target to the set distance, it determines whether the current state is to handle the color block or to place the color block. If it is to handle the color block, it enters the process of finding the tag to place the color block. If it is to place the color block, it will return to the process of finding the color block after placing it.

If the target is not detected, it records the number of times the target is lost and gradually increases it. If the number of times lost exceeds the set threshold, it resets the start_find_block flag and searches for the color block again.

First, the get_color_callback function is used to obtain the recognition result of the current color.

After recognizing the target color block, the robot will track the target in real-time through the head_track_process head PID and the body_track_process body tracking functions, gradually approaching the target color block. At this time, the body status is "approach".

  • Block Gripping

When approaching the color block to a certain distance, the body tracking state will change from "approach" to "align", which is the adjustment state. The robot will switch modes and perform turning adjustments in place.

Then, the picking-up state is judged. Since the program is initially set to "pick_block" by default, the robot will execute the action group self.move_up_action_name to pick up the color block, and reset the body tracking state to "approach". The find_tag_init function is called to initialize the steps for tracking and placing the color block on the tag.

    def get_color_callback(self, msg):
        # 获取颜色识别结果(obtain color recognition result)
        for object_info in msg.data:
            if object_info.type == 'rect':
                self.object_info = [object_info.x, object_info.y, object_info.angle, object_info.width, object_info.height]
                if self.transport_state == 'pick_block' and self.head_track_state != 'stop' and not self.start_find_block:
                    self.rl_dis, self.ud_dis = self.head_track_process(object_info.x, object_info.y, object_info.width, object_info.height)
                elif self.head_track_state == 'stop':
                    self.rl_dis, self.ud_dis = None, None
