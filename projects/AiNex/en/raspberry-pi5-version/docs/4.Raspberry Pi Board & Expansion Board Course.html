4.2.1 Buzzer Control ​

4.2.1.1 Brief Introduction ​

This section demonstrates on how to set the high and low voltage levels of the buzzer, enabling it to make sound after being powered on.

4.2.1.2 Getting Ready ​

There is an onboard buzzer on the Raspberry Pi expansion board, as shown below:

4.1.2.3 Operation Steps ​

NOTE

the input command should be case and space sensitive.

  1. Start Raspberry Pi mainboard, and connect it to MobaXterm.
  1. Enter the following command and press Enter key to navigate to the directory where the program is located.
bash
cd board_demo/
  1. Enter the following command. Press “Enter” to run the program.
bash
python3 buzzer_demo.py

NOTE

You can press the Tab key for quick command completion, or copy and paste the commands directly into the MobaXterm terminal by right-clicking the mouse. Please note that the “Ctrl+C” and “Ctrl+V” shortcuts are not supported for copy and paste in the MobaXterm terminal.

  1. If you want to exit the program, you can press “Ctrl+C”. If it fails, try again.

4.1.2.4 Program Outcome ​

When the program runs, the buzzer on the expansion board will beep once a second.

4.1.2.5 Code Analysis ​

The source code of the program is saved in: board_demo/buzzer_demo.py

python
#!/usr/bin/python3
# coding=utf8
import time
from ros_robot_controller_sdk import Board

board = Board()
print('buzzer di at 1hz')

try:
    while True:
        board.set_buzzer(1900, 0.1, 0.9, 1)
        time.sleep(1)
        board.set_buzzer(2400, 0.1, 0.4, 0)
        time.sleep(2)
except KeyboardInterrupt:
    board.set_buzzer(1900, 0, 0, 1)  # buzzer off

This program uses the Board class in the ros_robot_controller_sdk module. In a while loop, it calls the “set_buzzer()” function to control the buzzer. Specifically, the loop continuously executes the following steps:

  1. Import the necessary modules: time and ros_robot_controller_sdk.

  2. Enter an infinite loop. It will be interrupted after you press “Ctrl+C”.

  3. In each loop, call the “set_buzzer()” method to set the buzzer and make it emit sound.

    Take the board.set_buzzer(1900, 0.1, 0.9, 1) as an example:

    The first parameter "1900" is the frequency.

    The second parameter "0.1" is the duration of the on state.

    The third parameter "0.9" is the duration of the off state.

    The fourth parameter "1" is the number of repetitions. If it is 0, the loop will repeat indefinitely.

  4. If you press “Ctrl+C” to interrupt, the program will be closed by catching the KeyboardInterrupt.

4.2.2 RGB Control ​

4.2.2.1 Brief Introduction ​

RGB stands for the three color channels: red, green, and blue. The parameter range for each channel is 0 to 255. By modifying the parameters of RGB, the color of the RGB light can be changed.

4.2.2.2 Getting Ready ​

There is an onboard RGB light on the Raspberry Pi expansion board, as shown below:

4.2.2.3 Operation Steps ​

NOTE

the input command should be case and space sensitive.

  1. Start Raspberry Pi mainboard, and connect it to MobaXterm.
  1. Enter the following command and press Enter key to navigate to the directory where the program is located.
bash
cd board_demo/
  1. Enter the following command in the command input box. Press “Enter” to run the program.
bash
sudo python3 rgb_demo.py

NOTE

You can press the Tab key for quick command completion, or copy and paste the commands directly into the MobaXterm terminal by right-clicking the mouse. Please note that the “Ctrl+C” and “Ctrl+V” shortcuts are not supported for copy and paste in the MobaXterm terminal.

  1. If you want to exit the program, you can press “Ctrl+C”. If it fails, try again.

4.2.2.4 Program Outcome ​

After the program runs, the RGB lights on the Raspberry Pi expansion board will light up in red, green, and blue in turn. Each color will be displayed for 0.3 seconds.

4.2.2.5 Code Analysis ​

The source code of the program is saved in: board_demo/rgb_demo.py

python
#!/usr/bin/python3
# coding=utf8
import time
from ros_robot_controller_sdk import Board

board = Board()
board.set_rgb([[1, 0, 0, 0]])
while True:
    try:
        board.set_rgb([[1, 255, 0, 0]])  # 红(red)
        time.sleep(0.3)
        board.set_rgb([[1, 0, 255, 0]])  # 绿(green)
        time.sleep(0.3)
        board.set_rgb([[1, 0, 0, 255]])  # 蓝(blue)
        time.sleep(0.3)
    except KeyboardInterrupt:
        board.set_rgb([[1, 0, 0, 0]])
        break

This program uses the “Board” class in the “ros_robot_controller_sdk” module and sets the RGB light using the “set_rgb()” function.

Take the code “board.set_rgb([[1, 255, 0, 0]])” as an example.

The first parameter “1” represents the corresponding RGB light. The parameters “255, 0, 0” are the RGB color channel parameters. The “r” represents the value of the "R" channel (red component); “g” and “b” represent the values of the "G" and "B" channels, respectively.

4.2.3.2 Getting Ready ​

There is an onboard button on the Raspberry Pi expansion board, as shown below:

4.2.3.3 Operation Steps ​

NOTE

the input command should be case and space sensitive.

  1. Start Raspberry Pi mainboard, and connect it to MobaXterm.
  1. Enter the following command and press Enter key to navigate to the directory where the program is located.

You can press the Tab key for quick command completion, or copy and paste the commands directly into the MobaXterm terminal by right-clicking the mouse. Please note that the “Ctrl+C” and “Ctrl+V” shortcuts are not supported for copy and paste in the MobaXterm terminal.

4.2.3.4 Program Outcome ​

The program will print the value of the button status “key” during runtime. When the button is pressed, the value of “key” is 0. Otherwise, it is 1.

4.2.3.5 Code Analysis ​

The source code of the program is saved in: board_demo/button_demo.py

python
#!/usr/bin/python3
# coding=utf8
import time
import gpiod

#gpio引脚对应, 采用BCM编码(using BCM encoding for corresponding GPIO pins)
adapter_board_key = 13  # 按键(button)

chip = gpiod.chip("gpiochip4")

key = chip.get_line(adapter_board_key)
config = gpiod.line_request()
config.consumer = "key"
config.request_type = gpiod.line_request.DIRECTION_INPUT
config.flags = gpiod.line_request.FLAG_BIAS_PULL_UP
key.request(config)

if __name__ == '__main__':
    try:
        while True:
            print('\rkey: {}'.format(key.get_value()), end='', flush=True)  # 打印key状态(print button state)
            time.sleep(0.001)
        chip.close()
    except:
        print('按键默认被app_node占用，需要先关闭服务')
        print('~/.stop_ros.sh')

This code uses the “gpiod” library to configure the corresponding I/O port to obtain its status.

It is set to “DIRECTION_INPUT” (input mode) and “FLAG_BIAS_PULL_UP” (pull-up mode).

  1. Start Raspberry Pi mainboard, and connect it to MobaXterm.

bash
cd board_demo/
  1. Enter the following command in the command input box. Press “Enter” to run the program.

python3 imu_demo.py

NOTE

You can press the Tab key for quick command completion, or copy and paste the commands directly into the MobaXterm terminal by right-clicking the mouse. Please note that the “Ctrl+C” and “Ctrl+V” shortcuts are not supported for copy and paste in the MobaXterm terminal.

  1. If you want to exit the program, you can press “Ctrl+C”. If it fails, try again.

4.2.4.4 Program Outcome ​

When the program runs, the terminal will print the IMU data in real-time.

4.2.4.5 Code Analysis ​

The source code of the program is saved in: board_demo/imu_demo.py

python
#!/usr/bin/python3
# coding=utf8
import time
from ros_robot_controller_sdk import Board

board = Board()
board.enable_reception()

while True:
    res = board.get_imu()
    if res is not None:
        for item in res:
            print(" {: .8f}".format(item), end='')
        print()
    time.sleep(0.01)

This program uses the “Board” class from the “ros_robot_controller_sdk” module. It uses the “get_imu()” function to obtain IMU data and prints it on the terminal.

4.2.5 Raspberry Pi Expansion Board Configuration ​

If you use the image installed online using official tools to control the expansion board, please follow the steps below to configure the environment first.

  1. Refer to relevant tutorials in “4. Raspberry Pi Board & Expansion Board Course/1. Raspberry Pi 5 Controller” to configure the environment and hardware successfully.

  2. After correctly configuring according to the tutorial, open the “MobaXterm” remote connection tool and connect to the Raspberry Pi. For more specific instructions, please access lesson 2 in “1.Raspberry Pi 5 Controller/2. Raspberry Pi 5 Basic Operation and Configuration”.

  3. After connecting, enter the command to modify the serial port.

bash
sudo nano /boot/firmware/config.txt
  1. In the pop-up page, scroll to the end of the text. Enter the following code to modify the serial port configuration.
usb_max_current_enable=1
avoid_warnings=1
enable_uart=1
dtparam=uart0=on

  1. Press "Ctrl+S" to save. Then, press “Enter” and “Ctrl+X” in turn to return. After it returns, enter “sudo reboot” to restart the Raspberry Pi.

  2. After booting, enter the command to view the serial port direction.

bash
ls /dev - al

  1. Locate the content shown in the figure below, which indicates that the modification is successful.

  2. After the modification is successful, refer to lesson 2 in “1.Raspberry Pi 5 Controller/2. Raspberry Pi 5 Basic Operation and Configuration”, and transfer the “board_demo” in the appendix located in “2. Raspberry Pi Expansion Board Course” to the “/home/pi/” path of the Raspberry Pi.
